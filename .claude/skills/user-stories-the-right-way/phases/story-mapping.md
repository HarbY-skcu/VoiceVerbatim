# Map User Stories

Create a story map using the following rules.

1. Do not break stories into features.

2. Organize the map vertically as steps.

3. Place smaller concrete stories inside larger abstract stories.

4. Tell the story through the feature rather than decomposing the
   feature into implementation pieces.

5. Focus on the happy path.

6. Do not turn the story map into a flow chart.

7. Use stories to describe how individuals use the product.

8. When adding a feature to an existing product, do not remap the
   entire product.

9. Create a new story map that assumes the existing product is
   already being used.

10. Anchor releases to user outcomes.

11. Do not fill releases to capacity simply because space exists.
