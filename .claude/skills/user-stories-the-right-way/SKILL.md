# User Stories

## Process

Work through the following phases in order:

1. Define personas.
2. Create story cards.
3. Map the user stories.

Before beginning a phase, read its instruction file:

- `phases/personas.md`
- `phases/story-cards.md`
- `phases/story-mapping.md`

Do not read the instructions for later phases until that phase is reached.

Complete each phase before moving to the next one.
