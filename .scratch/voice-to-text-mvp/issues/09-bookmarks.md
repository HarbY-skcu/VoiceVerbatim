# 09: Bookmarks

**What to build:** Users can star any Note to Bookmark it. The Bookmarks sidebar tab lists only Bookmarked Notes, ordered by date last edited. Bookmarked Notes continue to appear in All Notes. The bookmark flag persists across app restarts.

**Blocked by:** 05 (Note Persistence & All Notes View)

**Status:** ready-for-agent

- [ ] A star/bookmark control is visible on each Note in All Notes and when a Note is open
- [ ] Toggling the bookmark flag on a Note adds or removes it from the Bookmarks view
- [ ] Bookmarks sidebar tab lists only Bookmarked Notes, ordered by date last edited
- [ ] Bookmarked Notes still appear in All Notes alongside non-bookmarked Notes
- [ ] Bookmark flag persists across app restarts
